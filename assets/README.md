# 拔草花园动画

`chiikawa-garden-web.gif` 为网页压缩版循环动画。乌萨奇和小八移步、蹲下拔草，再将草束装入篮子。`chiikawa-garden.gif` 保留为原尺寸版本。

草格采用 Anonymity-0 在 2025-11-02 至 2026-11-02 的 GitHub 贡献快照，共 639 次贡献。绿色深浅对应 GitHub 返回的贡献等级；快照随本次发布固定。

角色参考 [Chiikawa Dots Pets](https://github.com/heelee912/chiikawa-dots-pets) 的乌萨奇和小八形象，通过 imagegen 生成新的拔草姿势，再编排成动画。

本动画为非官方同人创作。Chiikawa 及相关角色归 Nagano 和相应权利人所有。
